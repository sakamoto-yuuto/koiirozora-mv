# 恋色空 — 视觉基准（v1，2026-10-22）

> 每个镜头都按本文件验收。依据：参考仓库的方法论（`docs/PLAN.md`），以及千本桜 MV 的研究（`research/senbon_study.md`）。
> 组件：`src/components/print.js`（印刷语言）、`world.js`（场所）、`phone.js`（电话机）、`src/scenes/kit.js`（歌词）。

## 1. 每一帧都是一张印刷品

1. **纸**：纸纹盖在所有画面上（`paper()`，由覆盖层统一画）。底色永远不是纯黑。
2. **光一律用网点**：路灯、荧光灯、窗光、LED 光晕都用 `dotLight`、`dotCone`、`dotFill`、`dotRing` 来画。网点越大，光越强。
   **全片唯一一处平滑渐变，是 320.44 s 的恋色天空。**
3. **阴影版**：实物（电话机、留言机、电话亭框、人物的深蓝墨版）都带一块错版的阴影版，偏移 6–16 px。剪切进来的那一刻，阴影版先被"拽"一下，再慢慢回位（`misreg(t, seed, { cut })`）。
4. **细描线**（v1 还没做全，下一轮补上）：建筑轮廓、窗框、电话亭框、栏杆，用一根 1.5–2 px 的细线勾一遍，颜色用 `text` 或 `ice`，低透明度。千本桜的金线就是这个作用：让平涂有结构，也让画面有细节。
5. **剪影**：人物一律是三墨剪影，不用代码画脸。"他"永远不露全身，只出现手、袖口、空位或房间。

## 2. 颜色＝状态
见 `docs/PLAN.md` §2。每一段只用那个状态的调色盘角色，场景代码里不写 hex。

## 3. 文字

### 3.1 她的歌词：竖排，逐字
- **默认位置在画面右侧**：日文竖排明朝体（`serif`，500/600），字号 56；中文小字（`zh`，24）竖排在它左边。
- **一个字落在它被唱出的那一刻**（`data/lyrics_film.json → chars[].t`，由 `tools/align_lyrics.py` 生成）：
  - 每个字的入场是 0.18 s 内从 6 px 外落到位，透明度跟着升起，类似活字被按上纸面；
  - 汉字带的假名注音一起出现。
- **上一句不立刻消失**：同一段落里，新的一句在左边另起一列，旧的一列压暗到 45 %。换段落、或者有画面事件时再整体收掉。
- **唱完以后的字会变成雪**：一句的最后一个字唱完约 1.5 s 后，这一列的每个字碎成 6–10 片网点雪花往下飘（对应「〔L9〕」）。
- 镜头自己负责排字时（字落在实物上），设 `lyric: 'none'`，由镜头来排。

### 3.2 关键词落在实物上
每个具体名词都要找一个 1986 年的、本来就印着字或可以写字的东西：

| 词 | 实物 |
|---|---|
| 恋色空（标题） | 雾玻璃上手指写的字 ✅ |
| 黄昏 / 街 | 商店街的街名招牌，竖排灯箱 |
| ふたり | 两只杯子上的字，或两张电话卡 |
| 時間(とき) | 留言机的磁带计数器 |
| さよなら | 车窗起雾的玻璃，手指写了一半 |
| 寂しさ | 一个个「寂」字像雪一样落下、积起来 |
| 声 | 听筒，或电话卡背面的打孔刻度 |
| 一人 | 电器行橱窗里所有电视的节目字幕条 |
| 世界中 | 公用电话旁的电话簿，或国际电话的计费表 |
| 温もり | 掌心融开的霜，字从霜里显出来 |
| 恋色の空 | 天空本身（唯一的渐变），字用纸签挂在电线上 |

- 字的动作就是那件实物的动作：挂、盖、写、落、亮起、跳一格。
- 汉字关键词加假名注音（`ruby`）。

### 3.3 机器的字
- 点阵（`lcd`）：电话和留言机的显示屏。
- 七段数码（`segDigits`）：度数和计数器。
- 等宽（`mono`）：读数面板的标签。

## 4. 动态

1. **镜头从不完全静止**：
   - 每个镜头至少有 `drift()` 手持游移，并有一个有方向的运动（推、拉、横移或升降）；
   - 镜头内部的运动只增不回，换方向就换镜头。
2. **视差**：至少三层（远、中、近），各自用不同的系数跟着 `camX` 走。
3. **雪**：中景雪 `snow()` 一直在飘，前景大雪片 `nearSnow()` 偶尔掠过镜头。
4. **会动的东西**：
   - 卷线在晃，听筒被拿起后余摆衰减；
   - 磁带轮在转；
   - 荧光灯启动时会闪；
   - 电线随风轻摆；
   - 她的剪影在呼吸（缩放 0.6 %），阴影版缓慢漂移。
5. **按拍反应**：拍点上有很轻的错版抖动（`beatEnv`），响铃时有微震加网点声波圈。
6. **转场优先用图形**：
   - 网点收缩成一个点或从一个点扩散；
   - 玻璃上的雾被擦开；
   - 胶片式的错版跳格；
   - 竖屏一拍开一扇；
   - 镜头横移带动态模糊（`ctx.trail`）。
   硬切永远落在拍上。

## 5. 声音（音效）
- 只有画面里的实物发出的声音才配音效：脚步、门、荧光灯、呼气、手指擦玻璃、听筒、插卡、按键、回铃音、铃声、继电器、磁带、「ピー」。
- 电话里的声音一律走听筒频段（300–3400 Hz）。
- **音量是相对于当地音乐响度的负值**（`rel`），任何时候都不能盖过音乐。
- 时间点写在各段的 `<section>Sfx(env)` 里，与画面共用一张时间表：`node tools/sfx.mjs` 导出，`tools/make_sfx.py` 合成并混进 `assets/audio/mix.wav`。
