## Timing tools
- `cues(env)` → `B(n)` bar starts, `Bt(b)`, `T(i)` line start, `P` = 0.8 s. **Cuts only on beats / half beats / bars.**
- `charTimes(env, i)` (kit.js) → `[{ c, t }]`: when each character of line i is sung (real alignment arrives in
  data/lyrics_film.json → chars; until then it is an even spread; ALWAYS read times through charTimes so the real data is
  used automatically). Events that must hit a syllable use `charTimes(env, i)[k].t`.

  `lyric: 'none'` and draws the line there (still one character per charTimes). Keep the right ~380 px calm when the column is on.
