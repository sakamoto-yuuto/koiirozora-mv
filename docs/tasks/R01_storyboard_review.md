# R01 审稿：恋色空 MV 分镜 v2（只读，不改任何文件）

你是一位有经验的动画 MV 分镜审稿人。请读：
- docs/STORYBOARD_v2.md（要审的分镜，时间单位为歌曲秒）
- research/lore.md（WHITE ALBUM 2009 动画与这首歌的背景）
- docs/VISUAL.md（视觉语言：三墨版画、网点光、竖排逐字歌词）
- data/lyrics_film.json 里的歌词行（歌词以歌ネット原文为准，不可改）

硬约束（不要提违反它们的建议）：
1. 唯一原则：每个画面不看任何文档也能看懂。
2. 冬弥只露背影和局部（手、肩、后脑），永不露正脸。
3. 全片一个美术层：人物、路人、背景都是同一种生成的三墨版画；代码只加光、雪、视差、镜头、字。没有科技风 HUD 面板。
4. 字幕只有右侧竖排一套；只有 4 个主角字（恋色空 / 黄昏 / 寂 / 恋色の空）落在实物上，落在实物上时竖排跳过，不重复。
5. 留言机只出现三次（接起、录音时间到被切断、片尾他按再生）。

请逐段回答，每条意见要具体到时间段和镜头：
A. 哪些镜头观众第一次看可能看不懂？为什么？怎么改最省？
B. 叙事是否连贯：她打电话→留言→被切断→再打→他回家听到。有没有逻辑漏洞（例如用件数、卡的度数、时间线、她在哪里）？
C. 与原作人物/设定的出入（由綺是偶像、冬弥的性格、1986 年左右的道具是否合时代）。
D. 节奏：哪里信息过密或过空，哪里该更大胆。
E. 你认为最弱的 3 个镜头，各给一个替代方案（必须满足硬约束、只用版画素材+代码能做到）。
最后用一段话总结优先级最高的 5 条修改。用中文，直接输出审稿意见，不要修改任何文件。
