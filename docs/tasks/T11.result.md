## 实现内容

- 单位为米，Z 向上，街道向 +Y 延伸。街道、电话亭、房间分别有明确命名与分组。
- 两排两层店铺、卷帘门、雨棚、二楼窗、电线杆、下垂电线、路灯、雪地与雪堆。电话亭位于街景画面右三分之一，由綺位于左半边。
- 同一座棕色 1985 型电话亭：三面玻璃与玻璃门、顶灯、小台板；绿色 MC-3P 粗模尺寸 0.23×0.26×0.37m，含听筒、卷线、12 键、卡槽、投币／返却部件、七段 LED。玻璃有独立隐藏标签。
- 六叠房间：3.6×2.7m，6 块榻榻米、中央矮桌、家用电话、独立磁带留言机、门、空衣钩、右侧真实开窗、书架、叠被。留言机用实体卷轴和指示灯表达，没有 LCD 句子。
- 由綺 1.60m、冬弥 1.75m；长发／牛角扣大衣与窄裤短靴、窄肩长腿／及大腿外套／背后浅色帽兜均以块面表示。每人 32 根骨骼，每只手有 5 根指根到指尖骨。网格使用实际 Armature modifier 与单骨权重，保存后可在 Blender Pose Mode 中编辑。
- 5 个镜头共 11 个姿态视图，输出 15 张导图；均为 1672×941。两套走路图每张包含 contact / down / passing / up 四帧。每帧机位一致，侧走双手可见；背影中冬弥在左、由綺在右，她左掌与他右掌共用目标。
- 电话亭机位处于亭内肩后，右食指接触第 6 键；目标为 `[3.659, 1.174, 1.369]`。

### 三种导图

- `line`：Workbench 隐面消除与对象／折线描边，白底黑线；可见左侧肢体蓝线，右侧红线。蓝／红是人物自身左右，不是画面左右。肩后镜头的左手被身体遮挡，重点只展示右手按键。
- `clay`：Cycles CPU 灰材质、环境平光加一盏面主光，固定种子，12 samples、降噪、AgX。无最终素材贴图。
- `depth`：Cycles 实际相机 Z 深度，`clamp((far-z)/(far-near), 0, 1)`，Raw 线性输出为 8-bit 灰阶 PNG，天空为黑。范围由 JSON 指定，同一四帧条带共用范围；不逐帧重新拉伸，避免明暗关系跳变。

## 运行方法

在项目根目录执行；仅本次 PowerShell 子进程使用脚本执行参数，不修改系统执行策略。

```powershell
# 重建 .blend、渲染所有镜头、生成总览、文件检查、6 项回归测试
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action all

# 只重建几何
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action build

# 改完 JSON 后，只重渲一个镜头
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action render -Shot street_wide

# 仅看线稿，快速调整构图；最终交付前再渲染全部通道
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action render -Shot walk_cycle_side -Passes line

# 分别复查交付文件和骨架／深度回归
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action verify
powershell.exe -NoProfile -ExecutionPolicy Bypass -File blender/run_previs.ps1 -Action test
```

底层仍是任务指定的后台 Python 流程，例如：

```powershell
$previsTmp = Join-Path $PWD 'blender/_tmp'
$env:BLENDER_USER_CONFIG = Join-Path $previsTmp 'config'
$env:BLENDER_USER_SCRIPTS = Join-Path $previsTmp 'scripts'
$env:TEMP = $previsTmp
$env:TMP = $previsTmp
& 'D:\Blender\blender-5.2.2-windows-x64\blender.exe' -b --factory-startup --python-exit-code 1 --python blender/render_guides.py -- blender/shots/street_wide.json
```

上述局部环境的创建、原值恢复由 `run_previs.ps1` 自动完成。当前受管沙箱中，普通 Python 再派生 Blender 会在初始化阶段返回 `0xC0000142`；已验证的正式入口是 PowerShell 原生调用 Blender。验证与 PNG 处理也全部使用 Blender 自带 Python / NumPy，无需安装 Pillow 或其他依赖。

## 修改机位或姿势

### 例 1：换街景机位并让她迈步

修改 `blender/shots/street_wide.json` 中以下字段，其余保留：

```json
{
  "camera": {
    "position": [-0.8, -9.5, 2.15],
    "target": [0.3, 16.0, 1.5],
    "lens_mm": 35
  },
  "characters": {
    "yuki": {
      "position": [-1.7, -0.5, 0.03],
      "heading_deg": -80,
      "pose": "walk",
      "phase": "passing"
    }
  }
}
```

相机位置／目标和角色位置均为世界坐标，单位米；`heading_deg` 绕 Z 轴，0° 面向 +Y。有 `ortho_scale` 时使用正交机位（竖直视野高度），`lens_mm` 此时只作记录；要改为透视，删除 `ortho_scale`。加入 `"orientation": "portrait"` 会输出 941×1672，需同时调整机位以适应竖构图。

### 例 2：摆手、按键和骨骼微调

`pose` 支持 `stand`、`walk`、`dial`、`hold_walk`。`hands` 默认指定手掌中心；`dial` 的 `R` 特别指定右食指末端接触点：

```json
{
  "pose": "dial",
  "position": [3.43, 0.73, 0.08],
  "hands": {
    "R": [3.659, 1.174, 1.369],
    "L": [3.25, 0.82, 0.97]
  }
}
```

手臂伸不到的显式目标会报 `unreachable`，接触误差容限为 0.005m。调整目标时也应调整站位。牵手时修改同一帧中由綺的 `hands.L` 和冬弥的 `hands.R` 为同一个坐标。`frames` 中的角色条目覆盖该帧基础条目；如果覆盖 `hands`，同时写出该角色两只手的目标。

可以在角色条目添加 `"bones": {"head": [0, 0, 12]}`。骨骼旋转为局部 XYZ 欧拉角（度）；完整名称见 `scene_manifest.json`，例如 `upper_arm.R`、`forearm.L`、`finger.index.R`。涉及已有手部接触约束的骨骼覆写仍要通过接触检查。

### 隐藏与单独场景

- `groups` 可选 `street`、`booth`、`room`、`character`。
- `hide_glass: true` 隐藏玻璃，保留框架和内壁装置。
- `hide` 支持对象名称、名称前缀和 `*` 通配符；房间示例隐藏 `Room.Wall.Front`、`Room.Ceiling`。
- `characters` 中省略某个人即可隐藏该人物。
- 所有镜头完成后会自动更新 `contact.png`；也可单独运行 `-Action contact`。

## 已知取舍

1. 这是预演粗模：方块服装、低面数头发、单节指骨、刚性权重，没有布料／发丝模拟、精细五官和完整碰撞系统。四个相位是可重复的原地步态参考，不是烘焙好的长段动画。
2. 保留同一地点尺度与构图关系，不追求与参考版画逐像素一致。房间从入口方向采用前墙／顶面剖开；导图默认隐藏玻璃，源 `.blend` 保留实际玻璃。
3. 为使每帧双手清楚，侧走摆臂有示意性夸张。牵手以两掌接触与单骨指形为约束，精细交扣与布料穿插留给后续导演／生图阶段。
4. `line` / `clay` 是几何说明，不保留材质颜色或 LED 点亮状态；七段显示器的段码结构会完整显出。实际棕亭、绿电话、衣服／头发颜色保存在 `.blend`。
5. 深度是按镜头固定范围归一化的 8-bit 导图，不是米制浮点 EXR。最终美术效果、人物连续动作质量与是否采用这些机位仍由导演验收。
6. `build` 会按脚本重建并覆盖 `previs.blend`。Blender 内的手工改动应先另存；需要可重复保留的机位／动作修改请写回 JSON，几何修改请写回相应 Python 模块。
