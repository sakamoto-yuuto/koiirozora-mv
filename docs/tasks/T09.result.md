# T09 导出提速实验结果

## 完成的改动

- `export/export.mjs` 现在默认选择项目内的 `node_modules/ffmpeg-static/ffmpeg.exe`；`--ffmpeg PATH` 和 `MV_FFMPEG=PATH` 均可覆盖。启动时记录实际路径、版本，以及 `h264_nvenc` / `libx264` 的编码器可用性。NVENC 探测失败会原样打印 probe stderr，并以 `FALLBACK: using libx264` 明示回退。
- `tools/export_parallel.mjs` 默认并发改为 4，不再强制 x264，而是把 `config.json` 的 `export.codec`（当前为 `auto`）传给 worker。其拼接/mux 也遵从 `--ffmpeg` / `MV_FFMPEG`，使覆盖是端到端一致的。
- 导出页默认使用有界（默认 3 帧）流水线：一帧的 ACK 不再阻止下一帧渲染；WebSocket ACK 采用 FIFO，帧缓冲只会在 ACK 后复用。旧的逐帧路径仍可完整启用，作为对照。
- WebGL 后处理在没有 B 场景时不再上传 A 的副本至 B；mix shader 在该条件下的 `uType=0`，不会采样 B。已用下文的逐字节原始帧验证此项不改变结果。
- 实现了 WebGL2 PBO + `fenceSync` 读回实验。单帧同次对照已经逐字节通过；但多帧 PBO 队列曾在当前 Chrome/ANGLE（RTX 3050）无头导出中停在 fence 轮询，故 PBO 默认关闭，仍可用开关显式复现/继续诊断；默认保留稳定的有界 WebSocket 流水线和同步 readPixels。
- 新增 `tools/bench_export.mjs`：按 240–244、320–326 秒，旧 x264 / 旧 NVENC / 新 NVENC 与 1/2/4 路的笛卡尔积串行运行；每项默认 2 次，记录含启动端到端 fps 和所有 worker 的帧循环 fps 到 `out/_t09/bench_results.json`。

## 开关

| 参数 | 默认 | 作用 |
| --- | --- | --- |
| `--pipeline 0/1` | `1` | `0` 为原始 `render → readPixels → ACK` 串行路径；`1` 为有界流水线。 |
| `--pbo 0/1` | `0` | WebGL2 PBO / fence 异步读回实验。当前机器默认关闭，避免无头 ANGLE fence 不发信号。 |
| `--skip-b-upload 0/1` | `1` | 没有 B 场景时跳过冗余 B 纹理上传。 |
| `--inflight N` | `3` | 同时在途的帧数，限制为 1–8。 |
| `--codec auto\|h264_nvenc\|libx264` | `config.json` 的 `auto` | 选择/探测编码器。 |
| `--ffmpeg PATH` 或 `MV_FFMPEG` | 项目内置 `ffmpeg-static` | 覆盖 FFmpeg 可执行文件（worker 与并行 mux 同时生效）。 |

## 完整测速矩阵

测量脚本和所有要求的组已实现，运行命令如下（每组串行、每项默认两遍）：

```text
node tools/bench_export.mjs
```

本次未能产生可接受的「旧 x264 / 旧 NVENC / 新 NVENC × 1/2/4 路」完整表：项目内置 `ffmpeg-static/ffmpeg.exe` 在开始任何导出前即以 Windows 状态 `0xC0000142` 退出；它正是当前 NVIDIA 驱动可用 NVENC 所需的二进制。系统 `D:\Tools\ffmpeg\bin\ffmpeg.exe` 可启动，但其 NVENC probe 报驱动 API 不匹配并回退 x264，因此不能把它伪列为 NVENC 成绩。此状态下脚本会留下明确失败而不是混入错误编码器的数据。

## 推荐命令

内置 FFmpeg 可正常启动的环境中，推荐以默认 4 路和稳定流水线导出：

```text
node tools/export_parallel.mjs --start 0 --end 395.4 --width 1280 --height 720 --fps 30 --jobs 4 --out out/film.mp4
```

继续定位 PBO 时使用（该机器多帧队列可能在 3 秒 fence 超时后明确失败，勿用于正式导出）：

```text
node tools/export_parallel.mjs --start 320 --end 326 --width 1280 --height 720 --fps 30 --jobs 2 --pbo 1 --out out/pbo_probe.mp4
```
