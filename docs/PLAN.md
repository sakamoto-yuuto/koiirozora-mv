# 恋色空 — 导演方案（v1，2026-10-22）

> 非官方同人歌词 MV。曲：森川由綺（CV 平野綾）「恋色空」，作詞 Bee'，作曲・編曲 藤間仁；TV 动画《WHITE ALBUM》(2009) 插入歌。
> 方法论来自 [world-execute-me-lyric-mv](https://github.com/Nyankomintsu/world-execute-me-lyric-mv)（引擎代码 MIT，见 `docs/THIRD_PARTY_LICENSE_world-execute-me.txt`；**不使用**其 CC BY-NC-SA 剪影）。
> 本文件是全片的工作契约：写任何一个镜头前先读它。考据见 `research/lore.md`，歌词与编曲见 `research/lyrics_and_music.md`。
> 歌词只在 `data/lyrics_film.json` 里，代码中用 `text(i)` 取，不在文档里引用整句。

## 1. 全片是一通电话

1986 年冬夜，没有手机。由綺在一座绿色公用电话亭里给他打电话。他不在家，留言机接了起来。

**整首歌就是她留在他留言机里的话。**

- **她**＝私：由綺。她唱出的每一句歌词，就是她对着话筒说的话。颜色是**酒红**（她的头发），字体是**明朝体**。
- **他**＝あなた：冬弥。**全片不露脸、不出声。** 他只以这些形式存在：没人接的铃声、留言机的应答文字、空房间、记忆里的一只手或一截袖口。颜色是**琥珀**（灯、体温）。
- **机器**＝线路本身：绿色公用电话 MC-3P、电话卡度数的 3 位红色 LED、留言机磁带和红色「用件」灯。颜色是**机器红**（LED），字体是点阵（DotGothic16）和七段数码。
- **冰蓝**＝寒冷和电话亭的荧光灯：雪、霜、玻璃。
- 实物考据见 `research/phone1986.md`：1985 型电话亭是棕／灰框（不是绿色），电话机才是暗松绿 `#2E6B55`；回铃音 400 Hz「1 秒响 2 秒停」，忙音「0.5 秒响 0.5 秒停」；卡插入即显示度数，市内每 3 分钟跳 1 度（片中做艺术压缩）。

故事线：
1. 雪夜走进电话亭，插卡，按号码。
2. 一直响铃，留言机接起，「ピー」一声。
3. 她开口：回忆一起走过的黄昏，每次说再见都想哭，寂寞像雪一样积下来，想听一点你的声音……
4. **留言时间用完，线路被切断**（2:54 深静音）。
5. 她再拨一次。街上电器行橱窗里的一排电视正在直播音乐祭：屏幕上的她被很多人簇拥着微笑，屏幕外的她一个人站在雪里。
6. 她再一次对着留言机说话：心冻僵了，请你温暖我，世上没有比你更温暖的……**电话卡度数归零，卡被退了出来。**
7. 她走出电话亭。线路已经断了，再没有机器帮她传话。最后一段副歌，她对着天空唱。
8. 「〔L26〕」：抬头。全片唯一的渐变。
9. 尾奏：他漆黑的房间里，留言机的「用件」灯一直在闪。一只琥珀色的手按下了「再生」。在声音出来之前，黑场。

> 结尾不写重逢（考据结论：歌词给的是天空，不是重逢）。按下「再生」只意味着**她的声音会被听见**。整部片子，就是他将要听到的那段录音。

**检验一个镜头**：「这是这通电话里的哪一刻？」
**检验一张版画**：「这是哪一个词？是什么结束了它？」

## 2. 颜色＝状态，只在发生了事的时候变

`config.json → palettes`，各状态的含义：

| 状态 | 意义 | 进入时机 |
|---|---|---|
| `snow` | 灰阶：线路还没通，或已经断了 | 片头；2:54 线路被切断 |
| `night` | 机器在运转：度数 LED 的红、电话亭荧光灯的冰蓝 | 插卡时红色 LED 亮起「50」，**全片第一个颜色**（20.21 s，乐队进入的小节线） |
| `voice` | `night` 加上酒红：她在说话 | 75.83 s 第一句 |
| `memory` | 纸底变暖，酒红和琥珀同框：两人在一起的回忆 | 只在回忆版画里 |
| `cold` | 冰蓝压过一切，酒红变暗：寂寞、冻僵 | C1 后半；C2 前半 |
| `tv` | 广播的冷白加饱和色 | 只在 V2 的电视橱窗段 |
| `koi` | 恋色：酒红和琥珀**第一次混合**成渐变的天空 | 320.44 s，唯一一次 |
| `dawn` | 天亮了，纸白 | 尾奏后段 |
| `dead` | 黑 | 片尾 |

全片固定的语义：**酒红＝她，琥珀＝他，机器红＝线路（LED、REC、度数），冰蓝＝寒冷，灰＝缺席。**

- 酒红和琥珀在 320.44 s 之前**永远是两块分开的平涂**，可以并排、可以错版，但绝不混色、绝不渐变。
- `koi` 这个角色色在 `koi` 之外的所有状态里都是灰，代码层面就保证它不会提前出现。
- 机器红（`err`）只用在机器的发光件上：度数 LED、REC 灯、用件灯。它不是情绪色。

## 3. 三种画面

| 种类 | 是什么 | 在哪里 |
|---|---|---|
| **线路**（界面） | 代码绘制的 1986 实物：电话亭玻璃（雾、霜、手指写的字）、绿色电话机、电话卡和度数 LED、按键、听筒和卷线；他房间的留言机（磁带轮、计数器、用件灯）。 | 全片贯穿 |
| **版画** | 她心里的画面：深色或纸色的底，平涂墨色加纸纹、网点、错版。具象剪影（codex 生成后分色）、雪的字形画、大字。 | 落在关键词和具体名词上 |
| **广播** | 电视画面：CRT、扫描线、节目字幕条、观众席、计分板式的字。 | **只在 V2**（187.85–213.05 s） |

- 版画在拍点上进入，由**线路上的一个事件**结束：度数跳一格、磁带计数器进位、玻璃上的雾被擦掉、听筒的卷线晃过画面等等。版画不会无缘无故地来去。
- 质感标准（照搬参考）：
  - 每个镜头至少三层：底、主体、前景或界面。
  - 底永远不是纯黑。
  - 界面是哑光的，只做局部发光。
  - 动作要缓动、错开、带二次运动，**不只靠透明度淡入淡出**。
- 字体分工：
  - 明朝体（Shippori Mincho）＝她说的话，也就是歌词。
  - 黑体（Noto Sans JP）＝印刷品和广播。
  - 点阵（DotGothic16）＝机器显示屏。
  - 手写（Klee One）＝手指在雾玻璃上写的字。
  - 等宽（JetBrains Mono）＝计数器和数字。
  - 中文译文用 Noto Serif SC，小字。
  - 除此之外不用别的字体。
- **歌词**：
  - **v1 只有日文**（用户 2026-10-22 决定；中文译文保留在 `data/lyrics_film.json`，开关是 `config.json → lyricsZh`）。竖排在右侧，逐字随演唱出现（`docs/VISUAL.md` §3.1）。
  - 关键词在版画里做成大字，不再在字幕带上重复。
  - `時間(とき)` 用注音（ruby）的形式排。

## 4. 角色剪影（`assets/art/`）

- 生成流程：`tools/codex_gen.sh` 并发跑（一次 12–16 个），绿幕原图存 `art_src/`，`tools/key_art.py` 抠成干净的 RGBA 放进 `assets/art/`。
- codex 生成，风格是**三墨平涂丝网版画**：米白 `#F1E9DA`、酒红、深蓝黑 `#1B2230`，加一点冰蓝只给发夹；底是纯绿 `#00FF00`，抠掉。
- 他的部分用琥珀代替酒红：只画手和袖口，**不画他的脸和身体**。
- 载入时分成三块墨版（`art.inks`）。每块墨版对应一个调色盘角色，可以各自错版或显影。
- 身份锚点：
  - 酒红棕长直发，过胸，中分略偏右，侧刘海蓬松。
  - 浅蓝一字发夹。
  - 米白高领针织衫。
  - 身形纤细、克制，19 岁。
  - 私密的镜头里，她绝不露出偶像式的笑。
- 脸的画法：
  - 无脸，或者闭眼时只画两笔。
  - 只有 `y_eye` 一张画眼睛，留给 C2 和 C3 的特写用。
  - **不扭曲五官、不让嘴动、不用代码画脸。** 有脸的画面上不做撕裂和变形转场，只用错版。
- 清单和状态见 `assets/art/ART_LIST.md`（生成后补）。

## 5. 时间

- **75.00 BPM 恒速**：beat 0 在 0.21 s，一拍 0.8 s，一小节 3.2 s，`downbeatPhase` = 1。
  - 这是对 onset 强度做 72–80 BPM 精细搜索的结果，只有一个尖峰；节拍追踪器报的 150 是双倍速。
- **所有剪辑点都落在拍、半拍或小节线上**。镜头内部的事件可以落在实测的人声起音上，统一写在 `src/scenes/cues.js`，一个点一行，注明来源。
- LRC 时间普遍比小节线晚约 0.2 s（弱起）。字幕跟 LRC 走，切点跟网格走。
- 所有时间都是**歌曲时间**；不设片头警告页（全片没有高频闪光，preroll = 0）。

## 7. 交付与检查

- `node export/export.mjs --sheet out/qa.png --times ...`：把指定时间点渲染成缩图表。每段做完都要出一套逐拍缩图，由我审片。
- `npm run storyboard`：从代码里的镜头表生成 `STORYBOARD.md`。要求每一行歌词都有镜头，每个切点都在拍上，每个镜头都写清 `moment`。
- 闪光检查（`tools/check_flash.py`）、音画同步检查（`tools/check_sync.py`）在导出预览片之后跑。
- 每张具象版画都要单独渲染成检查卡（不带歌词）来判断：不读任何文字就能认出画的是什么，才算通过。
