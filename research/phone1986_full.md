# 1986 年前后日本“绿电话 / テレカ / 电话音 / 留守番電話”实物考据

> 调研目的：为代码绘制 1986 年东京冬季的公共电话、电话卡、答录机与声音可视化提供可落地的实物参数。
>
> 标记约定：
> - **【事实】**：有网页/官方资料直接支撑。
> - **【推断】**：根据照片、操作逻辑、同年代机型复原，不能当作实测数据。
> - **【可视化建议】**：给绘制的近似参数，不是史料。
>
> 文中“度”= テレホンカード的计数单位，1 度 = 10 日元。

---

## 0. 先把 1986 年的时间线钉住

| 时间 | 事件 | 依据 |
|---|---|---|
| 1982-12-23 | 电电公社（现 NTT）开始发行、销售テレホンカード；卡式公话登场 | [テレホンカード（Wikipedia）](https://ja.wikipedia.org/wiki/%E3%83%86%E3%83%AC%E3%83%9B%E3%83%B3%E3%82%AB%E3%83%BC%E3%83%89) |
| 1984 | 卡专用公话机导入 | [NTT 東日本「公衆電話機のうつりかわり」](https://www.ntt-east.co.jp/databook/history-public-phone-1982-1997.html) |
| 1985-04 | NTT 推出“ハウディ・レポンス III 形”，把留守番电话功能整合进家用电话机 | [NTT 東日本「電話機のあゆみ 1985–1997」](https://www.ntt-east.co.jp/databook/history-telephone-1985-1997.html) |
| 1985 | NTT 新电话亭登场：浅棕、深棕、灰三种配色，强调耐震、遮音、防雨、照明 | [NTT 東日本「公衆電話ボックスのうつりかわり」](https://www.ntt-east.co.jp/databook/history-public-phone-booth.html) |
| 1986-05 | 小型绿电话 **MC-3P** 开始提供服务；1984-04 开始开发，是 MC-1PN 的小型化 | [「公衆電話の記録」MC-3P](http://chirashino.blogspot.com/2014/09/mc-3p.html) |

**一句话结论**：1986 年东京街头最典型的组合不是“绿电话 + 绿电话亭”，而是 **绿色 MC-3P 电话机 + 棕色/灰色 1985 型电话亭 + 橙色钠灯或青白水银灯 + 发光的罐装咖啡自贩机**。电话亭本身在 1985 年已经改成浅棕/深棕/灰，不是电话机的绿色。

## 1. NTT 绿色公用电话（緑電話，MC-3P / MC-3PNC）

### 1.1 型号与定位：1986 年该画哪一台？

**【事实】**
- MC-3P 是 1982 年卡式公话的小型轻量化版本，1984 年 4 月开始开发，**1986 年 5 月提供服务**。
- 开发目的：让原本难以桌面设置的 MC-1PN 可以放进电话亭、桌面、柜台。
- 尺寸 **W23 × D26 × H37 cm**，重量 **14 kg**。
- 硬币投入口合并为一个；停电时 100 日元硬币仍可使用；按键与 100 日元粉色电话 675P 同款；可发出“使用硬币/使用卡”的识别信号；支持自动拨号卡。
- 来源：[「公衆電話の記録」MC-3P](http://chirashino.blogspot.com/2014/09/mc-3p.html)

**【事实】型号关系**
- **MC-1PN**：初代卡式公话，体积约为 MC-3PNC 的 3 倍，卡 + 10/100 日元硬币。
- **MC-2**：与 MC-3PNC 同尺寸，但**卡专用**。
- **MC-3PNC**：卡 + 10/100 日元硬币，是 MC-1、MC-2 的后继，也是全国最常见的一代。
- 来源：[Wikimedia Commons: MC-3PNC](https://commons.wikimedia.org/wiki/File:MC-3PNC.JPG)

**【事实】MC-5P 不是 1986 年的机器**
- MC-3P 于 1986 年 5 月上市；MC-5APN / MC-5BPN 等 MC-5 系属于 **1987–88 年起的卡专用小型机**。
- 所以画 1986 年，应选 **MC-3P / MC-3PNC**，不要选 MC-5P。
- 来源：[「公衆電話の記録」機種一覧](https://chirashino.blogspot.com/2018/09/blog-post.html)；[食玩魂 公衆電話ガチャ増補版](https://www.butsuyoku.net/shokugan/public_telephone2/)

**【推断】**
- 1986 年 5 月刚上市时，东京街头的 MC-3P 与旧式 MC-1PN / MC-2 会并存；不是一夜替换。画“常见”可以画 MC-3P，画“刚出现”可以画它旁边还有旧机。
- 机体铭牌可能仍写“日本電信電話株式会社”或 NTT；1985 年民营化后，“電電公社”字样应逐步消失。

### 1.2 正面布局：哪些能考，哪些是复原

> 说明：**“部件存在”是事实；“相对位置”是根据公开实物照片、操作顺序和同年代机型复原的，标为推断。** 真正绘制时，建议按下面的示意定比例，不要声称是工程图。

**【事实】存在的部件**
1. 送受话器（听筒/话筒一体）与卷线。
2. 3×4 拨号键盘（1–9、*、0、#）。
3. テレホンカード插入口；同一口兼作退卡口。
4. 10 日元 / 100 日元硬币投入口。
5. 硬币返却口/返却杆。
6. 度数显示（LED）。
7. 操作说明贴纸、卡插入方向箭头。
8. 电话机与电话亭之间的连接线/端子。

**【推断】正面相对位置（从左到右）**

```
┌──────────────────────────────────┐
│  ┌──────┐   ┌─────────┐  ┌────┐  │
│  │      │   │  [105]  │  │CARD│  │ ← 3位红色LED / 卡槽
│  │ 受話 │   ├─────────┤  ├────┤  │
│  │  器  │   │ 1  2  3 │  │COIN│  │ ← 硬币投入
│  │      │   │ 4  5  6 │  ├────┤  │
│  │      │   │ 7  8  9 │  │RET │  │ ← 硬币返却
│  │      │   │ *  0  # │  └────┘  │
│  └──────┘   └─────────┘          │
│           [ 操作说明贴纸 ]        │
└──────────────────────────────────┘
```

- 听筒在**左侧**，竖向挂在托架上；卷线从机身左下或听筒下端出。
- 键盘在**中部偏右**，3 列 × 4 行；按钮是圆角方形/圆形，浅灰或灰绿色，白字。
- 3 位 LED 在键盘上方偏左，嵌在深色小窗里；显示剩余度数。
- 卡槽在**右侧**，横向插卡；卡的长边（85.6 mm）水平进入。
- 硬币投入口在卡槽上方或紧邻卡槽上方，是一条横向细缝，旁边印“10”“100”。
- 硬币返却口在右下，带一个可按压的返却杆/按钮。
- 最下方是说明贴纸，通常印“受話器を取る → カードを矢印の方向に差し込む → ダイヤルする”。

**【推断】为什么这样排**
- 右手拨号、右手插卡/投币，左手拿听筒，是日本公话的典型人机关系。
- 卡槽必须放在右侧，避免与听筒卷线打架；硬币返却口放在右下，方便按。
- 卡槽兼退卡口有专利直接说明：“テレホンカード挿入孔は、テレホンカード排出孔を兼ねている場合もある。”
  - 来源：[WO1993001943A1](https://patents.google.com/patent/WO1993001943A1/ja)

**【可视化建议】比例**
- 机身：W:D:H = 23:26:37。
- 正面分栏：左侧听筒约 30%，中间键盘约 40%，右侧卡/币区约 30%。
- 键盘按钮直径约为机身宽度的 5%–6%；LED 数字高度约为机身宽度的 4%–5%。
- 这些是画图比例，不是实测。

### 1.3 度数 / 金额 LED：1986 年显示的是“度”，不是“日元金额”

**【事实】**
- 卡插入后，电话机前面会**数字显示卡内记录的剩余度数**，并随通话时间减算。
- 剩余度数到 0 之前可以反复使用；硬币与卡并用时，按**卡 → 10 日元 → 100 日元**的顺序收纳。
- 来源：[NTT 東日本「公衆電話機のうつりかわり」](https://www.ntt-east.co.jp/databook/history-public-phone-1982-1997.html)；[NTT 西日本 PDF](https://www.ntt-west.co.jp/info/databook/pdf/090-094_koshudenwa_utsurikawari.pdf)

**【事实】位数**
- 当时最大面额有 105 度；要显示“105”，至少需要 **3 位**。
- 来源：[テレホンカード（Wikipedia）](https://ja.wikipedia.org/wiki/%E3%83%86%E3%83%AC%E3%83%9B%E3%83%B3%E3%82%AB%E3%83%BC%E3%83%89)

**【推断】显示样式**
- 3 位 7 段红色 LED，黑/深红滤波窗；数字高约 10–12 mm；段间有轻微辉光。
- 插卡后先显示“105”或“50”，通话中逐度递减；“105 → 104 → 103 …”。
- 余额 0 时可能显示“0”或熄灭；不同机型不一致。
- **1986 年的 MC-3P 不显示“金额（円）”，也不显示“可通話時間”**；这些是 1990 年代数字公话的功能。画“105”比画“¥1,050”准确。

**【可视化建议】**
- 用 3 位 7 段字体，红色 #FF3B1F，外面加一层暗红玻璃和轻微 bloom。
- 数字变化不要做成平滑滚动，而是**一秒内硬切**，像老 LED 的段码跳变。
- 可以画一位数字短暂“半亮”，表现扫描/余辉。

### 1.4 颜色：官方色号没找到，给近似值

**【事实】**
- 机体是绿色；NTT 资料与 gacha 商品都称“緑の公衆電話”“グリーンのカラーリング”。
- 来源：[NTT 東日本 公衆電話機](https://www.ntt-east.co.jp/databook/history-public-phone-1982-1997.html)；[電撃ホビー](https://hobby.dengeki.com/news/822115/)

**【推断】近似色**
- 机体主色：**#2E6B55**（深松绿，略偏蓝）。
- 阴影：**#1B4336**；高光：**#4A8069**。
- 键盘面板：**#3A4A42**（深灰绿）；按钮：**#B9BDB6**（浅灰）；按钮字：**#1A1A1A**。
- LED：**#FF3B1F**；卡槽/硬币口金属：**#C9CDD2**；说明贴纸：米白 **#F2E8D5** + 红字。
- 这些是从实物照片目测的近似值，不是 NTT 官方色号；没有找到公开的“NTT 绿”色票。

**【可视化建议】**
- 绿电话不要画成荧光绿或草绿；它是偏暗、偏蓝的“松针绿”。
- 在暖色街灯下，绿色会偏黄；在青色水银灯下，绿色会偏冷。可以做环境色影响。

### 1.5 电话亭（電話ボックス）：1985 型，棕/灰，不是绿色

**【事实】**
- 1985 年新电话亭：除玻璃外的部分有**浅棕（ライトブラウン）、深棕（ダークブラウン）、灰（グレー）**三种配色。
- 比旧型更宽；在**耐震、防暑、遮音、防雨、照明**上做了强化。
- 来源：[NTT 東日本「公衆電話ボックスのうつりかわり」](https://www.ntt-east.co.jp/databook/history-public-phone-booth.html)

**【推断】外观**
- 铝合金框架 + 三面透明玻璃 + 一扇门；下部有非透明踢脚板。
- 平顶或微坡顶，四周有浅色檐口；顶部可能有“TELEPHONE”或 NTT 标识。
- 内部有荧光灯，门开/关时点亮；有电话簿架/小台板；顶部或侧上方有通风百叶。
- 尺寸约 90 cm × 90 cm × 210 cm（推断）；电话机挂在后壁，站立使用。
- 1986 年东京街头使用的是 1985 型；旧型 1964 式玻璃盒可能仍少量并存。

**【可视化建议】**
- 棕色框架用 **#6B4A36**，深棕用 **#3E2C22**，灰用 **#8A8A86**。
- 玻璃不是完全透明：带一点绿灰、灰尘、指纹和雨雾；夜里内部灯光形成“发光盒子”。
- 冬季玻璃内侧可能有雾气/水珠，边缘有冷凝结露。
- 亭顶灯建议用冷白荧光（略偏绿），与街灯橙/青白形成对比。

### 1.6 使用顺序（画动作时别画错）

**【事实】**
- 先取听筒，再插卡或投币；顺序反了，卡/币会被退回。
- 来源：[チャレジョブセンター桶川「公衆電話の使い方」](https://www.challe-job.co.jp/21229/)；[NTT 西日本 PDF](https://www.ntt-west.co.jp/info/support/teiden.pdf)

**【事实】模拟机（MC-3P）与数字机的顺序不同**
- **MC-3P 是模拟公话**：先取听筒 → 插卡/投币 → 这时才听到发信音（“ツー”）→ 拨号。
- 数字公话才是“先取听筒听发信音 → 再插卡/投币 → 拨号”。
- 来源：[NTT 西日本「公衆電話の種類と使用方法について」](https://www.ntt-west.co.jp/info/support/teiden.pdf)

**【事实】**
- 卡在通话中保持在机内；通话结束或余额 0 时从同一槽退出。
- 硬币与卡并用时，优先扣卡，其次 10 日元，最后 100 日元。
- 100 日元硬币不找零。

**【推断】**
- 插卡后会有短促的机械“咔哒/嗡”声，卡被吸入；退卡时同样有机械声。
- 这些声音适合做 ASMR 细节，但具体音色随机型变化，不要当成统一标准。

## 2. テレホンカード：1986 年的面额、扣减与退卡

### 2.1 1986 年常见的面额与度数

**【事实】**
- 1 度 = 10 日元。
- 50 度：售价 500 日元。
- 105 度：售价 1,000 日元；其中 100 度是本金，5 度是赠分。
- 首发时还有 100 度 / 300 度 / 500 度；后来 100 度以上加赠，改成 105 / 320 / 540 度。
- 来源：[テレホンカード（Wikipedia）](https://ja.wikipedia.org/wiki/%E3%83%86%E3%83%AC%E3%83%9B%E3%83%B3%E3%82%AB%E3%83%BC%E3%83%89)；[NTT 東日本 磁気テレホンカード](https://www.ntt-east.co.jp/ptd/contents/mag_card.html)

**【推断】**
- 1986 年最常出现在钱包里的是 **50 度与 105 度**；320/540 度高额卡也有，但不如前两者日常。
- 100/300/500 度旧卡可能仍在流通，但新售卡已逐步转为加赠版。
- 画“105”比画“100”更有 1986 年的时代感。

### 2.2 卡的外观与尺寸

**【事实】**
- 尺寸：**高 54 mm × 宽 85.6 mm × 厚 0.76 mm**，角 R3.0；与信用卡同规格。
- 来源：[収集ワールド 商品页](http://sccw81.com/products/detail2752.html)

**【事实】**
- 正面：图案/照片、NTT 标识、面额“50度”或“105度”、卡名。
- 背面：磁条、使用说明、**打孔式剩余度数目安**（一排数字，孔打在刻度旁）；孔穿透卡体，正反面都可见。
- 使用中会打孔；孔只是目安，准确余量要插电话机看显示。
- 来源：[テレホンカード（Wikipedia）](https://ja.wikipedia.org/wiki/%E3%83%86%E3%83%AC%E3%83%9B%E3%83%B3%E3%82%AB%E3%83%BC%E3%83%89)；[ママつぶ「度数の見方」](https://mama-tubu.com/telephone-card-dosu/)

**【推断】**
- 1986 年卡面设计非常多样：风景、动物、偶像、企业广告等；没有统一的“1986 年卡面”。
- 卡的边角会有磨损、折痕、轻微弯曲；磁条有细划痕；打孔边缘有纸屑/毛边。
- 插卡方向通常按卡面箭头；磁条面朝向由机型决定，画的时候不要画成“磁条朝外”。

### 2.3 度数怎么扣：按 10 日元脉冲，不是按秒平滑减少

**【事实】**
- 市内公话：1970 年起 10 日元 / 180 秒；1976 年加入电话也改为 10 日元 / 180 秒；1986 年仍沿用。
- 来源：[市内通話（Wikipedia）](https://ja.wikipedia.org/wiki/%E5%B8%82%E5%86%85%E9%80%9A%E8%A9%B1)

**【事实】**
- 卡式公话在通话接通、收到计费脉冲时扣 1 度；之后每来一个 10 日元脉冲扣 1 度。
- 也就是说，**显示是按“度”跳变的**：105 → 104 → 103，而不是 105.0 → 104.9。
- 来源：[JPH07203087A（公衆電話機）](https://patents.google.com/patent/JPH07203087A/ja)

**【推断】**
- 市内 3 分钟扣 1 度；50 度卡理论上市内 150 分钟，105 度卡理论上市内 315 分钟。
- 长途/手机按距离与时段，10 日元可通话时间更短，度数掉得更快。
- 中途挂断时，已经扣掉的 1 度通常不按秒退还；公话按 10 日元单位计费。
- 100 日元硬币投入时按 100 日元单位收纳，不找零。

**【可视化建议】**
- 用“每 3 分钟跳 1 度”的节奏做画面，不要每秒钟减 0.05。
- 如果画面只有 30 秒，可以压缩成“每 2–3 秒跳 1 度”的视觉节奏，但要标注是艺术压缩。

### 2.4 余额 0 与“余额少”的提示

**【事实】**
- 通话中卡余额到 0，或硬币用完时，会通过听筒发出**蜂鸣/催促音**，提醒用户追加卡或硬币。
- 如果不追加，通话会在剩余时间用完时被强制切断。
- 来源：[JPH07203087A](https://patents.google.com/patent/JPH07203087A/ja)

**【事实】**
- 余额 0 或通话结束时，卡会从**同一个插入口**退出；卡式公话的插入孔兼排出孔。
- 来源：[WO1993001943A1](https://patents.google.com/patent/WO1993001943A1/ja)

**【推断】**
- 1986 年的 MC-3P 没有语音提示“残り度数が少なくなりました”；语音引导是 1990 年代数字公话才普及的。
- “余额少”的提示主要是**显示数字变小**；部分后期机型会在个位数时让显示闪烁，但 1986 年 MC-3P 的确切阈值没有找到一手资料。
- 0 度时的声音是蜂鸣器/催告音，不是人声；具体频率没有统一标准，画成 1–2 kHz 的短促“ブー/ピー”即可。
- 卡退出后，画面可以接“手接住卡、卡面打孔、余额 0”的细节。

**【可视化建议】**
- 0 度瞬间：LED 从“1”跳到“0” → 0.3 秒蜂鸣 → 波形骤停 → 卡槽机械退出 → 手接卡。
- 不要画“余额不足，请充值”之类的中文语音；1986 年没有这种提示。

## 3. 日本电话音：频率与通断节奏

### 3.1 三种最常用的音

| 音 | 频率 | 节奏 | 听感 | 来源 |
|---|---|---|---|---|
| 发信音 / 拨号音（DT） | **400 Hz 单音** | 连续 | “ツー——” | [発信音（Wikipedia）](https://ja.wikipedia.org/wiki/%E7%99%BA%E4%BF%A1%E9%9F%B3) |
| 呼出音 / 回铃音（RBT） | **400 Hz，15–20 Hz 调制** | **1 秒通、2 秒断**（周期 3 秒） | “プー……プー……” | [呼出音（Wikipedia）](https://ja.wikipedia.org/wiki/%E5%91%BC%E5%87%BA%E9%9F%B3) |
| 话中音 / 忙音（BT） | **400 Hz** | **0.5 秒通、0.5 秒断**（周期 1 秒） | “ツー、ツー” | [話中音（Wikipedia）](https://ja.wikipedia.org/wiki/%E8%A9%B1%E4%B8%AD%E9%9F%B3) |

**关于“16 Hz”**：
- 你说的 16 Hz 是**对 400 Hz 载波的调制频率**，不是单独发出的低音。
- 日本规范写的是 **15–20 Hz 调制**；16 Hz 是常见近似值。画频谱时，主峰在 400 Hz，两侧有 ±16 Hz 的边带。
- 呼出音是“1 秒 ON / 2 秒 OFF”，不是“1 秒通 1 秒断”。忙音才是 0.5/0.5。

### 3.2 合成配方（给代码）

**【可视化建议】**
- 采样率 44.1 kHz；正弦波 400 Hz；淡入淡出 5 ms，避免爆音。
- 发信音：`sin(2π·400t)`，连续，振幅 0.15。
- 呼出音：
  - 载波 `sin(2π·400t)`；
  - 调制 `1 + 0.3·sin(2π·16t)`（或 15–20 Hz）；
  - 门控：`t mod 3.0 < 1.0` 时发声，其余静音；
  - 振幅 0.18。
- 忙音：
  - `sin(2π·400t)`；
  - 门控：`t mod 1.0 < 0.5`；
  - 振幅 0.18。
- 答录机提示音：约 1 kHz、0.3–0.5 秒短音（推断，不是日本统一规格）。
- 卡余额 0 催告音：1–2 kHz 蜂鸣、短促重复（推断）。

### 3.3 声音可视化

**【可视化建议】**
- 波形：400 Hz 正弦，1 秒约 400 个周期；画面不要画成“噪声”。
- 频谱：一条 400 Hz 亮线；呼出音在主峰两侧有 ±16 Hz 的细边带。
- 节奏：用 3 秒循环的“亮 1 秒、暗 2 秒”表示回铃；用 1 秒循环的“亮 0.5、暗 0.5”表示忙音。
- 老电话听筒的频响窄，400 Hz 听起来“薄”；可以加一点 800 Hz 谐波和轻微失真。

## 4. 1980 年代家用留守番電話（答录机）

### 4.1 典型外观：米色盒子 + 卡带 + 红色 LED

**【事实】**
- 1985 年 4 月起，NTT 的“ハウディ・レポンス III 形”把留守番电话功能做进家用电话机；此前也有独立的答录机。
- “レポンス”有 3 种类型：
  1. 应答专用机（只能放应答语，不录音）；
  2. **微型盒带 1 盘**的应答录音机；
  3. **标准盒带 2 盘**的应答录音机（一盘放应答语，一盘录留言）。
- 来源：[NTT 東日本「電話機のあゆみ 1985–1997」](https://www.ntt-east.co.jp/databook/history-telephone-1985-1997.html)

**【事实】**
- 留言媒体长期是**标准盒带（コンパクトカセット）**，之后大量转向**微型盒带（マイクロカセット）**；微型盒带可以用 2.4 模式在微型录音机上回放。
- 来源：[留守番電話（Wikipedia）](https://ja.wikipedia.org/wiki/%E7%95%99%E5%AE%88%E7%95%AA%E9%9B%BB%E8%A9%B1)

**【推断】典型 1986 年家用机外观**
- 米白/奶油色塑料机身，长方形，宽约 25–30 cm，深约 20 cm，高约 8–12 cm（含电话听筒则更高）。
- 左侧电话听筒座；右侧卡带仓，带烟色透明窗，能看到两盘卡带的卷轴。
- 面板上方：**1–2 位红色 LED 用件计数器**；有新留言时闪烁，播放后常亮或归零。
- 面板按钮：留守/解除、再生、停止、消去、应答语录音；可能有机械式磁带计数器（3 位）。
- 侧面或背面：音量滑杆、麦克风、扬声器格栅、电话线接口。
- “留守”指示灯为红色；有的机型用 LED 数字，有的用机械计数器，不能一概而论。

**【可视化建议】**
- 米色 **#D8CFC0**，深棕 **#4A3A2E**，烟色窗 **#3A2E28**，红色 LED **#FF2A1A**。
- 卡带卷轴用两个白色齿轮，缓慢反向转动；磁带厚度可用一条深棕细线表示。
- 红色 LED 以 1 Hz 闪烁；按钮有轻微凹陷和高光。

### 4.2 标准应答语（日文措辞）

**【事实】**
- 日本答录机的经典应答语是：
  > 「ただいま留守にしております。ピーという発振音が鳴りましたらお名前と御用件をお話し下さい。」
- 大意：现在家中无人。听到“哔”的发信音后，请说出您的姓名和事由。
- 来源：[留守番電話（Wikipedia）](https://ja.wikipedia.org/wiki/%E7%95%99%E5%AE%88%E7%95%AA%E9%9B%BB%E8%A9%B1)

**【事实/常见变体】**
- 「ただいま留守にしております。発信音のあとに、お名前とご用件をお話しください。」
- 「ただいま外出しております。ピーという発信音のあとに、ご用件をお話しください。」
- 注：Wikipedia 写的是“発振音”，但日常/说明书更常见“発信音”；两者指的都是提示音。

**【推断】**
- 1986 年的应答语多为机主自己录，语速较慢、音质窄带、带磁带底噪；不一定是标准女声。
- 提示音通常是“ピー”一声短音，然后开始录音；不是音乐、不是语音倒数。

### 4.3 留言时长限制与“到时会怎样”

**【事实】**
- 每通留言的录音时间“大抵是 30 秒左右”。
- 来源：[留守番電話（Wikipedia）](https://ja.wikipedia.org/wiki/%E7%95%99%E5%AE%88%E7%95%AA%E9%9B%BB%E8%A9%B1)

**【推断】**
- 30 秒到限：机器发出短促提示音，然后切断/停止录音；对方如果继续说话，不会再被录进去。
- 磁带录满：机器可能停止应答，或播放“これ以上録音できません”之类的提示；不同机型不同。
- 留言件数计数到上限：新留言不再录，LED 可能快闪或熄灭。
- 这些行为随机型差异很大，画动画时建议只表现“30 秒 → 哔 → 断”，不要虚构具体日文提示。

**【可视化建议】**
- 画一条 30 秒的磁带长度条，走到头时“咔”一下停住，红色 LED 从闪变常亮。
- 卡带卷轴在录音时缓慢转动；停止时突然静止。
- 电话听筒里可以叠一条窄带人声，加带通滤波（300–3,400 Hz）和轻微底噪。

## 5. 1986 年东京冬季街景（可选）

> 这一节是“氛围复原”，不是精确史料。能考的是电话亭与自贩机的年代，街灯颜色与天气是推断。

### 5.1 电话亭周边

**【事实】**
- 1985 型电话亭：浅棕/深棕/灰框，玻璃，重视照明、遮音、防雨。
- 来源：[NTT 東日本](https://www.ntt-east.co.jp/databook/history-public-phone-booth.html)

**【推断】**
- 东京街头多为棕色框；车站前、商店街、路口、公园入口各一台。
- 亭内荧光灯常亮；冬天玻璃内侧起雾，外侧有灰尘和手印。
- 亭顶/侧面有“TELEPHONE”或 NTT 标识；旁边可能有电话簿架、烟灰缸、自动贩卖机。

### 5.2 自动贩卖机

**【事实】**
- 罐装咖啡在 1970 年代出现，**1980 年代广泛普及**；原因是防止自动贩卖机内高温保存导致的“flat sour”变质技术成熟。
- 来源：[imidas「缶コーヒー」](https://imidas.jp/genre/detail/F-111-0167.html)

**【推断】**
- 1986 年东京街头：红色可口可乐自贩机、罐装咖啡（UCC、Pokka 等）、果汁、香烟自贩机。
- 机器正面有明亮的荧光灯背光，价格多为 100 日元；按钮式选择，取物口有塑料挡板。
- 冬天热饮柜（あたたか〜い）开始常见；罐身有“HOT”标记。
- 自贩机的光与电话亭的光是夜景的两个主要光源。

### 5.3 街灯颜色

**【推断】**
- 1980 年代日本一般街路仍大量使用**水银灯**，光是青白/浅绿白，显色偏冷。
- 干线道路、隧道、部分街区开始用**高压钠灯**，光是橙黄/琥珀色。
- 东京冬季空气干燥，光晕明显；电线杆、变压器、电线切割天空。
- 画夜景时，可用“青白水银灯 + 橙黄钠灯 + 电话亭冷白荧光 + 自贩机暖白”的四色光。

### 5.4 冬季氛围

**【推断】**
- 东京冬季（12–2 月）干燥、少雨、晴天多，早晚冷；街头常见大衣、围巾、口罩。
- 落叶树裸枝、常绿树深绿；路面有干尘，偶尔湿冷。
- 人行道上有热饮罐、电话卡、烟蒂、免费纸巾广告；电话亭玻璃有雾气。
- 不要默认“大雪”；东京冬季雪不多，画“晴冷干燥”比“雪景”更稳妥。

## 6. 最适合做成画面母题的 10 个细节

> 选择标准：一眼能认出 1986 年、适合特写、能承载声音/时间/情绪。

1. **3 位红色 LED 的倒数**
   - 105 → 104 → 103；数字硬切、暗红玻璃、轻微 bloom。
   - 声音：每跳一度“嗒”一声，或直接静音，只留环境声。

2. **电话卡背面的打孔刻度**
   - 一排数字 + 孔洞；孔边有毛边；卡角磨损。
   - 特写：手指抚摸孔洞，像在数还剩多少时间。

3. **听筒与卷线**
   - 绿色听筒、黑色卷线、听筒上的口水/灰尘/划痕。
   - 声音：拿起/放下的“咔嗒”，卷线拉伸的摩擦声。

4. **卡槽的金属唇与箭头贴纸**
   - 卡插入一半停住，箭头指向机内；金属反光。
   - 声音：卡被吸入的机械“嗡/咔”。

5. **硬币投入口的“10 / 100”字样**
   - 10 日元与 100 日元共用一口；旁边有返却杆。
   - 声音：硬币落入的“哐啷”，返却时的“咔哒”。

6. **棕色电话亭的发光玻璃盒**
   - 夜里，亭内冷白荧光，玻璃起雾，外面是橙/青街灯。
   - 声音：远处车流、亭内灯管的 50/60 Hz 嗡声。

7. **电话卡正面的人像/风景**
   - 1986 年的卡面设计多样；不要用现代极简风。
   - 特写：卡面反光、磁条、边角折痕。

8. **答录机的红色 LED 与卡带卷轴**
   - 红色 LED 1 Hz 闪烁；两盘卡带缓慢转动；烟色窗。
   - 声音：磁带底噪、卷轴“沙沙”、提示音“ピー”。

9. **400 Hz / 1 秒–2 秒的声音图形**
   - 波形、频谱、3 秒循环的门控；400 Hz 主峰 + 16 Hz 边带。
   - 画面：把回铃音画成“亮 1 秒、暗 2 秒”的呼吸光。

10. **冬季街角的光色关系**
    - 青白水银灯、橙黄钠灯、电话亭冷白、自贩机暖白。
    - 声音：自贩机压缩机低鸣、风声、远处电车/广播。

## 7. 容易画错的地方（建议贴在画布边）

1. **MC-5P 不是 1986 年的机器**：它是 1987–88 年起的卡专用小型机。1986 年选 MC-3P / MC-3PNC。
2. **电话亭不是绿色**：1985 型是浅棕/深棕/灰；绿色是电话机。
3. **LED 显示的是“度”，不是“日元”**：1986 年 MC-3P 不显示金额，也不显示可通话时间。
4. **没有语音提示**：1986 年没有“余额不足请充值”的女声；只有显示和蜂鸣。
5. **16 Hz 是调制，不是低音**：主音是 400 Hz；16 Hz 只是让声音“颤”的调制。
6. **电话卡不是“刷卡”**：是插入并保持在机内，通话结束/余额 0 时从同一口退出。
7. **100 日元不找零**：这是当时公话的真实痛点，也是电话卡普及的原因之一。
8. **答录机不一定有 LED 计数器**：1980 年代也有机械计数器；LED 是常见高配，不是唯一。
9. **电话卡尺寸是 85.6 × 54 mm**：和信用卡一样，不要画成名片或明信片。
10. **不要默认东京冬季大雪**：东京冬季以晴冷干燥为主，雪少；画“冷光、呼气、玻璃雾”比画雪更准。

## 9. 最后一句

如果只能画一个母题：**让 3 位红色 LED 从 105 开始，每 3 分钟跳 1 度地减到 0；背景里是 1 秒通、2 秒断的回铃节奏；0 的瞬间蜂鸣、断线、卡从同一个槽退出。**  
这一个画面同时包含了 1986 年的电话、电话卡、声音节奏和时间感，比单独画一台电话机更有叙事性。
